LEGO City Undercover Color Changer Mod

DLL mod that changes the UI color in LEGO City Undercover

How to use

Alongside the DLL you will need a color.json file in the same folder.

The file must contain the following fields: rainbow, speed, red, green, and blue. Colors use standard RGB values (0-255).

{ "rainbow": false, "speed": 1, "red": 255, "green": 255, "blue": 255 }

Save the file and restart the game if it's already running. Note that some colors may appear darker than others this is to keep the ingame menus readable.

You will need a way of loading a DLL file, DLL files are executables eg .exe but they cannot be ran just by double clicking.

Option 1, DLL Loader. Check out DLL Loader, drag the Color Changer DLL and the color.json file into the injected folder.
